# Phase 23 — Search & Internal Linking

Implemented:
- Lightweight menu search.
- Search results with item URLs.
- Category-grouped menu explorer.
- Internal links from menu to item detail pages.
- Search empty state.

SEO/UX rule:
Navigation should help users reach menu, nutrition, prices, locations and tools naturally. Do not create artificial link networks or keyword-stuffed navigation.
