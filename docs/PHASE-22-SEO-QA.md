# Phase 22 — SEO, AEO, GEO, AIO & QA Foundation

Added:
- Canonical metadata base.
- Open Graph and Twitter metadata.
- Web app manifest.
- Organization JSON-LD helper.
- Breadcrumb JSON-LD helper.
- Health/status page.

QA principles:
- One clear H1 per indexable page.
- Direct answers near the top of informational pages.
- Tables and concise facts where users need comparisons.
- Source, verification date and uncertainty shown for volatile data.
- Contextual internal links.
- No mass-generated thin location pages.
- No fabricated reviews, prices, nutrition or official affiliation.
- JSON-LD must describe only content actually visible/true on the page.
- Canonical URLs must match the final production domain before launch.
