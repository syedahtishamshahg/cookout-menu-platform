# Cook Out Menu Platform

Independent Cook Out Menu & Price Intelligence Platform — menu, prices, nutrition, locations, interactive tools, SEO, AEO, GEO & AI-ready.

## Foundation
Next.js + TypeScript, mobile-first UI, metadata, robots/sitemap, and a data-first architecture.

## Principles
- Independent/unofficial resource; never imply affiliation.
- Do not fabricate prices, nutrition, locations, reviews, authors, or sources.
- Location-specific data should carry source/verification metadata.
- Build useful tools and structured information before scaling pages.
